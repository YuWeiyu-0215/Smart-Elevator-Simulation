\# 基于仿真的电梯调度优化系统



\## 一. 项目简介



本项目面向校园宿舍楼学生集中使用电梯的场景，建立电梯运行与学生乘梯过程的仿真模型，通过模拟学生乘梯需求和电梯运行过程，研究不同调度方式对电梯运行效率的影响。



项目主要关注学生的等待时间、乘梯时间以及电梯利用率等指标，并通过仿真数据对电梯运行情况进行分析，为后续电梯调度优化提供参考。



\---



\## 二. 项目背景



在上课/训前、下课/训后等高峰时段，大量学生可能同时产生乘梯请求，从而导致电梯等待时间增加、停靠次数增多以及运行效率下降。



因此，本项目尝试通过计算机仿真的方式模拟宿舍楼中的电梯运行过程，对不同乘梯需求和调度策略进行实验和分析。



\---



\## 三. 核心功能



本项目主要实现以下功能：



\- 学生乘梯请求生成

\- 学生起始楼层与目标楼层设置

\- 电梯运行过程模拟

\- 电梯开门、关门过程模拟

\- 电梯调度

\- 学生等待时间统计

\- 学生乘梯时间统计

\- 电梯利用率计算

\- 仿真结果统计与分析



\---



\## 四. 仿真模型



项目以校园宿舍楼为应用场景，对学生乘梯需求和电梯运行过程进行模拟。



主要参数：



\- 相邻楼层高度：3.5 m

\- 开门时间：2.6 s

\- 关门时间：2.6 s

\- 电梯运行方式：匀加速 + 匀速 + 匀减速

\- 短距离运行方式：匀加速 + 匀减速

\- 乘梯人员：学生



系统根据学生的起始楼层、目标楼层以及当前电梯状态进行调度，并记录整个运行过程中的相关数据。



\---



\## 五. 调度与优化



电梯调度是本项目的核心问题。



当多个学生同时产生乘梯请求时，系统根据当前电梯状态和请求情况决定电梯下一步的服务对象。



调度过程中主要考虑：



\- 电梯当前位置

\- 电梯当前运行方向

\- 学生所在楼层

\- 学生目标楼层

\- 当前等待请求

\- 电梯运行距离

\- 电梯停靠情况



通过改变调度策略并进行多次仿真，可以比较不同策略下的运行结果，为电梯调度优化提供依据。

\## 六. 评价指标



本项目通过多个指标对改造前后的电梯运行情况进行评价，主要包括以下指标：



\### 平均侯梯时间



学生从产生乘梯请求开始，到电梯到达其所在楼层并能够进入电梯所经历的平均时间。



\### P95侯梯时间



P95侯梯时间表示95%的学生侯梯时间不超过该数值，可以用于反映大多数学生的侯梯体验，并观察少数长时间等待的情况。



\### 最大侯梯时间



统计所有学生中的最大侯梯时间，用于观察极端情况下的等待情况。



\### 平均乘梯时间



学生进入电梯后，到达目标楼层并完成下梯所经历的平均时间。



\### 电梯利用率



用于衡量仿真过程中电梯实际运行时间所占的比例，反映电梯的运行使用程度。



\### 无效停靠次数



用于统计电梯在停靠过程中没有实际完成有效乘客服务的停靠次数，可用于分析调度过程中不必要的停靠。



\### 平均每次出发载客人数



用于统计电梯每次开始运行时平均搭载的学生人数，可以反映电梯的载客情况。



通过以上指标，可以从学生乘梯体验、电梯运行效率和调度效果等多个方面对系统进行分析。

\## 八. 实验结果



本项目在相同仿真条件下，对改造前后的电梯调度方案进行模拟，并对学生乘梯体验和电梯运行情况进行对比。



本次实验共模拟 \*\*700 名学生\*\*，改造前后均完成全部学生的运输。



\### 实验结果对比



| 指标 | 改造前 | 改造后 |

| --- | ---: | ---: |

| 总学生人数 | 700 | 700 |

| 完成运送人数 | 700 | 700 |

| 完成率 | 100.00% | 100.00% |

| 平均侯梯时间 | 64.91 s | 33.42 s |

| P95侯梯时间 | 156.29 s | 77.59 s |

| 最大侯梯时间 | 215.46 s | 128.66 s |

| 平均乘梯时间 | 65.08 s | 31.22 s |

| 开门次数 | 4103 | 526 |

| 关门次数 | 4102 | 526 |

| 开关门动作总数 | 8205 | 1052 |

| 无效停靠次数 | 3655 | 1 |

| 平均每次出发载客人数 | 4.47 人 | 3.09 人 |

| 电梯运行利用率 | 48.25% | 19.38% |



\### 改造前后变化



根据本次仿真结果：



\- 平均侯梯时间变化：48.52%

\- P95侯梯时间变化：50.36%

\- 最大侯梯时间变化：40.29%

\- 开门次数变化：87.18%

\- 无效停靠变化：99.97%



从本次仿真结果可以观察到，改造后的调度方案在侯梯时间、乘梯时间以及无效停靠次数等指标上均发生了明显变化。



需要说明的是，以上数据仅代表\*\*本模型及当前随机种子下的一次仿真实验结果\*\*，不能直接作为现实电梯系统实际运行效果的预测。

\## 九. 后续优化



目前项目主要实现了三部电梯的运行仿真、学生乘梯需求模拟以及基础调度功能。后续计划从以下几个方面进一步完善：



\### 1. 多电梯协同调度



目前项目主要针对三部电梯进行仿真。后续可以扩展为多部电梯同时运行，根据不同电梯的位置、运行方向和当前任务，对乘梯请求进行合理分配。



\### 2. 高峰期客流模拟



进一步模拟教学楼上课前、下课后等不同时间段的学生客流情况，使乘梯请求更加接近实际校园场景。



\### 3. 调度策略优化



在现有调度方式的基础上，增加不同的调度策略，并通过平均等待时间、平均乘梯时间和电梯利用率等指标进行对比分析，从而寻找更加合理的调度方案。



\### 4. 更真实的电梯运行模型



进一步完善电梯运动模型，考虑电梯加速度、最大运行速度、楼层停靠时间以及乘客进出电梯时间等因素，使仿真结果更加接近真实电梯运行过程。



\### 5. 可视化与交互



增加更加直观的电梯运行可视化界面，实时显示电梯所在楼层、运行方向、学生等待人数以及当前任务等信息，使仿真过程更加直观。



\### 6. 实验数据分析



增加多组实验和数据可视化，对不同客流量、不同调度策略下的实验结果进行比较，进一步分析影响电梯运行效率的主要因素。
